# Kitaplık

Personal library reader for Android. Kotlin + Jetpack Compose, no cross-platform
runtime. Fetches a `catalog.json` describing every file in the library, downloads
individual items on demand, and hands PDFs off to whatever reader is installed.

## Layout

```
app/src/main/java/com/erkantaylan/kitaplik/
├── catalog/     Models + CatalogSource (HTTP today, Drive later)
├── download/    Resumable downloader with size + MD5 verification
├── storage/     Where downloaded files live on device
├── open/        Hand-off to external apps via FileProvider
└── ui/          Compose screens and view model
```

## Dev loop

```bash
./dev.sh              # serve library, open tunnel, build, install, launch
./dev.sh --logs       # ...and tail logcat
```

The library is served from `../library` over an `adb reverse` tunnel on port
8090, so the device talks to `localhost` and nothing depends on the LAN address.
If the phone drops off Wi-Fi, `../env-setup/adb-wifi-connect.sh` reconnects it.

## Driving the app

`./kctl` targets elements by test tag or visible text, reading the accessibility
tree rather than guessing coordinates:

```bash
./kctl status                 # device, focused app, tunnel
./kctl ui                     # what is on screen, with tap points
./kctl tap base-pdf           # tap by tag substring or visible text
./kctl long base-md           # long press (deletes a downloaded copy)
./kctl tap search             # then: ./kctl type "murakami"
./kctl shot out.png           # screenshot
./kctl files                  # what has been downloaded
./kctl logs -n 100
```

Screenshots and taps **refuse to run unless Kitaplık is the focused app**, so
tooling can never capture or interfere with whatever else is on the phone.

The same commands are exposed over MCP by `tools/mcp_server.py`, registered in
`../.mcp.json`. Screenshots come back as images rather than paths.

## Catalog

`catalog.json` is generated by `../books/scripts/build-catalog.mjs` and is the
only contract between the app and its storage backend:

```bash
node ../books/scripts/build-catalog.mjs --root ../library --out ../library/catalog.json
```

One entry per file — a PDF, an EPUB and a markdown rendering are separate items
with separate handling, not formats of a shared parent.
